# 教員フィードバック確認票

- Audience: 授業担当者と評価協力者
- Status: Review material
- Last reviewed version: 0.1.0
- Classification: Audit material
- Related: [Teacher Demo](teacher-demo-script-ja.md), [First-year Check](../first-year-usability-check.md)

この確認票はオンライン送信を行いません。授業検討時のメモとして使用します。

- [ ] 表示は授業で分かりやすいか。
- [ ] COMET Mode の段階表示は適切か。
- [ ] Circuit とデータの同時表示は十分か。
- [ ] 初学者にとって情報量は多すぎないか。
- [ ] CASL Mode と COMET Mode の違いを説明しやすいか。
- [ ] Reverse Instruction と Reverse Microstep の違いが明確か。
- [ ] IN の WaitingInput 操作は分かりやすいか。
- [ ] 課題提出時に画面表示で混乱しないか。
- [ ] WCASL と比べて不足している点は何か。
- [ ] 授業で使うなら必要な改善は何か。
- [ ] 学生に紹介する場合の注意点は何か。
- [ ] proprietary project format 非対応という制限は十分に明確か。

記録時は、viewport、language、program、操作手順を添えてください。学生名、認証情報、提出内容はリポジトリへ保存しないでください。
