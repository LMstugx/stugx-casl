# Phase 15D: New, Demo Guards, And Unload Safety

## Scope

Phase 15D adds real empty New documents, routes built-in example selection through the file lifecycle guard, unifies New/Open/example replacement, and enables native browser unload protection while the current document is Dirty. It does not add projects, multiple files, recent files, source/session persistence, automatic execution, or custom unload text.

## Shared Replacement Intent

`open-file`, `new-document`, and `select-example` are stable machine intents. Preparation detects Dirty state, invalid targets, and repeated-example no-ops. The pending intent survives locale rerenders and is never derived from dialog text, filename, example title, or DOM selection.

All successful paths use the same controller and atomic store replacement. Open remains asynchronous; New and example factories are synchronous but still receive operation IDs and stale-document checks.

## New Document Behavior

The toolbar New command opens an application-owned dialog with explicit CASL II and C++ choices. Cancel has initial focus; Escape/backdrop cancel; Tab remains contained. A new document receives fresh document/source-unit IDs, origin `untitled`, no filename, `.cas` or `.cpp`, empty content, revision and saved revision zero, and Save As-only capability. It is clean and VM NotLoaded/Idle, with no automatic Assemble or Run.

`Untitled`, `無題`, and `未命名` are generated by the presentation helper. Localized text is not stored as identity or used as the Save As filename; defaults remain `main.cas` and `main.cpp`.

## Demo Selector Lifecycle

The controlled Demo selector requests a `select-example` intent and keeps its prior value until commit. Dirty documents receive Save/Discard/Cancel. Save failure, cancellation, or an edit made during Save blocks the switch. Each committed example creates a fresh clean working document and cannot mutate the immutable example definition. Re-selecting the active example is a no-op.

## Intent-Aware Unsaved Guard

The same dialog uses complete localized action strings:

- Open: Save/Discard and open;
- New: Save/Discard and create;
- Example: Save/Discard and switch.

The internal decisions remain `save`, `discard`, and `cancel`. Save uses Save or Save As according to the current transient binding. Cancel is the safe initial action. Dialog text can update for EN/JA/zh-CN without changing the pending intent.

## Atomic Replacement And Ownership

Replacement synchronizes the document, source text, language, and selected-example metadata while invalidating diagnostics, selected diagnostic/range, editor markers, Generated CASL, Machine Code, source maps, Trace, assembly/VM state, FramePlan preview/slot selection, write binding, and stale source-unit work. Locale, theme, observation mode, Circuit preference, and global lesson progress remain.

No intermediate new-source/old-runtime state is committed. Replacement does not parse, assemble, transpile, run, step, or create a code diagnostic.

## BeforeUnload Policy

`useBeforeUnloadDirtyGuard` delegates to a single-listener manager. Only derived document Dirty enables native `beforeunload`; clean documents have no handler. The manager prevents unload using the standard browser contract, supplies no custom prompt text, performs no save/storage work, and cleans up on unmount.

## Session Metadata Boundary

The version-1 metadata validator permits only last language/example and non-source UI preferences. Source, paths, handles, target IDs, document/source IDs, diagnostics, VM state, raw errors, locale, and operations are prohibited. Phase 15D performs no metadata storage or restore.

## Locale, Diagnostics, Security, And Accessibility

Locale is an application preference and remains unchanged by replacement. Diagnostics remain owned by a source unit and are cleared only on successful replacement; cancellation/failure preserves them. The Phase 14 baseline is unchanged.

New and guard dialogs use modal semantics, safe focus, Escape/backdrop cancellation, keyboard-contained controls, and intent-specific accessible action names. Filenames and example titles remain plain text. No source/path/handle/target/session data is persisted, and no browser prompt is imitated.

## Visual And Viewport Results

Injected visual scenarios cover New in all locales, Untitled CASL/C++, New and Demo Dirty guards, a guarded-save busy state, and a long example title at 1280x720. The capture uses no native picker. Toolbar, selector, Source header, natural page scrolling, bounded panels, and Circuit clean-wire behavior retain their established contracts.

## Known Limitations

- The native unload prompt wording is browser controlled and is not exercised as real navigation in E2E.
- Session metadata is a validated future contract only; nothing is persisted or restored.
- There is one current document and no project/recent-file model.
- Built-in example titles and long lesson content remain outside this localization pass.

## Phase 15E Recommendation

Run a file-lifecycle compatibility and race audit across New/Open/Save/example replacement, then freeze a lifecycle baseline before designing optional non-source preference restore. Do not add project or source persistence until that baseline is explicit.
