## Security Audit Follow-up

After the original `v1.0-rc1` tag, a local self-check added `pnpm audit` and found dev dependency blockers in Vite / Vitest tooling. Phase 12D-SEC patched those blockers:

- `vite` `5.4.21` -> `6.4.3`.
- `vitest` `2.1.9` -> `3.2.6`.
- transitive `esbuild` `0.21.5` -> `0.25.12`.

The blocker affected dev/test tooling, not emitted CASL or runtime semantics. See [v1-security-audit-notes.md](../v1-security-audit-notes.md). Final `v1.0.0` must be based on the security-patched commit or a later passing commit, not directly on the original `v1.0-rc1` tag.

## Known Limitations

- Not a full C++ compiler.
- No arrays / pointers / references.
- No recursion.
- No stack-frame locals.
- No stack arguments.
- No live frame slot values.
- No custom circuit editor.
- No production deployment.
- No full screen-reader audit.
