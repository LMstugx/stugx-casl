Open Project Overview and choose `Changelog`, `変更履歴`, or `更新日志` for offline release notes in the current locale.

The current build version determines the Current badge. Release channels distinguish stable, preview, and desktop-demo entries. Older entries can be expanded with keyboard or pointer input.

The application and repository `CHANGELOG.md` are generated from the same typed local registry. No GitHub or Cloudflare API is queried at runtime.

The Changelog does not check for updates, download software, record read state, add a storage key, or send telemetry.
