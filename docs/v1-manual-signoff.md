## 3. Required Manual Checks

- Smoke test: launch, default demo, assemble, step, run, reset.
- Focus Mode visual check: LD, ADDA, ST, index addressing, PUSH / POP, CALL / stack-aware RET.
- Observation Modes: CPU Flow, Register / Stack, Code / Machine.
- Learning flow: Guided Lessons, Study Mode checklist, Generated CASL, Machine Code explanation, Trace.
- Runtime views: registers, memory, Stack Preview, Call Stack, Signal Probe.
- C++ path: C++ Function Arguments demo and GR1-GR3 argument convention.
- FramePlan design preview: verify it remains design-only and does not imply live stack-frame slots.
- Keyboard-only walkthrough.
- Viewport checklist: 1280x720, 1440x900, 1920x1080.

## 5. Known Limitations Acceptance

Before final sign-off, reviewers must accept the v1.0 limitations documented in [v1-scope-freeze.md](v1-scope-freeze.md):

- not a full C++ compiler;
- no arrays, pointers, or references;
- no recursion;
- no stack-frame locals;
- no stack arguments;
- no live stack-frame slot values;
- no custom circuit editor;
- no production deployment;
- no full screen-reader audit.
